# 🧮 Calculadora React

Una calculadora moderna desarrollada con **React**, que permite realizar operaciones básicas (suma, resta, multiplicación y división), manejo de **decimales**, uso de **paréntesis**, y **borrado parcial** de entradas.

## 🚀 Características

* Interfaz limpia y responsive
* Soporta operaciones con paréntesis `( )`
* Control de decimales (evita desbordes del display)
* Botón de borrado parcial (elimina el último carácter)
* Operaciones básicas: `+`, `-`, `×`, `÷`
* Implementada con **React Hooks**

## 🧩 Tecnologías usadas

* React
* HTML5
* CSS3
* JavaScript (ES6+)

## ⚙️ Instalación y ejecución

1. Clonar el repositorio

   ```bash
   git clone https://github.com/tu-usuario/calculadora-react.git
   ```
2. Entrar al proyecto

   ```bash
   cd calculadora-react
   ```
3. Instalar dependencias

   ```bash
   npm install
   ```
4. Ejecutar en modo desarrollo

   ```bash
   npm start
   ```
